Python Labs for OpenIntro Statistics

A collection of lab files to teach how to perform statistical data analysis with Python for OpenIntro Statistics, a free and open-source textbook (2019, 4th edition).
The lab files are processed with Jupyter Notebook, and available at GitHub. Don't forget to give a Star and help spread the word!
